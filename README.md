# ぽんぽんあそび

2歳児向けのタップあそび19種類（ころころボール、シールちょう、ゆびのおうち、とけい、ABCパズル、ふうせん、どうぶつ、おえかき、いろタッチ、いろさがし、かぞえよう、すうじ、いないいないばあ、おみせやさん、もしもし、かたちはめ、でんしゃ、ぬりえ、あいうえお）。

- 単一の `index.html` で動きます（外部スクリプトなし）。
- 「おみせやさん」は https 上ならフロントカメラでおもちゃの色を読み取って「ピッ」と鳴ります。
- ホームの ⚙️ を 1.5 秒長押しで大人用の設定（音・カメラ・ABCなど）。
- ホーム画面に追加して（Android / iOS）、オフラインでも遊べます（PWA: `manifest.webmanifest` / `sw.js`）。
